# CHEMZ CREATIVE — Website

Website portfolio satu halaman untuk CHEMZ CREATIVE. Dibuat menggunakan HTML, CSS, dan JavaScript murni sehingga bisa langsung dipublikasikan melalui GitHub Pages.

## Struktur file

- `index.html` — struktur dan konten website
- `styles.css` — tampilan, layout, dan responsive design
- `script.js` — menu mobile, filter portfolio, animasi reveal, dan tombol WhatsApp

## Sebelum dipublikasikan

1. Buka `script.js`.
2. Cari `const WHATSAPP_NUMBER = "628XXXXXXXXXX";`.
3. Ganti dengan nomor WhatsApp bisnis, format kode negara 62 tanpa tanda +, spasi, atau angka 0 di depan.
4. Ganti email dan tautan Instagram di `index.html` dengan kontak resmi.
5. Ganti gambar contoh pada bagian portfolio dengan foto/video atau karya asli CHEMZ CREATIVE.
6. Simpan perubahan.

## Publikasi melalui GitHub Pages

1. Buat repository baru di GitHub, misalnya `chemz-creative`.
2. Upload seluruh file dari folder ini ke root repository (pastikan `index.html` berada di root).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses deployment selesai. GitHub akan menampilkan alamat website, biasanya:
   `https://USERNAME.github.io/chemz-creative/`

## Catatan

- Website ini tidak memerlukan build step atau framework.
- Font menggunakan Google Fonts dan foto contoh menggunakan Unsplash, sehingga koneksi internet diperlukan untuk memuat aset tersebut.
- Pastikan memiliki hak penggunaan atas semua foto yang dimasukkan ke website.
